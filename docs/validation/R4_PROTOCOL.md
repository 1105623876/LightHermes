# R4 固定验证协议（运行前，2026-10-02）

本协议在新结果产生前写入。原冻结 LoCoMo/holdout 不运行、不改变。所有数据为临时合成数据；不迁移用户真实记忆。现有 env 模型用于有限任务回放，不让模型执行任意 shell 或代码。

## 规模与树对照

- seed=4204；100、1,000、10,000 个 active 条目；向量维度 1024；相同 SQLite、FTS5 与生产 SemanticIndex 路径。
- 正常 API 写入事件/条目，以生产增量批次补齐固定本地向量。记录构建、修改、纠正/遗忘、重复去重、物理磁盘与向量有效载荷大小。
- 每档一个新连接首查与 10 个不同查询的热查，报告 p50/p95（小样本探索性，不是稳定尾延迟估计）；首查不是操作系统冷缓存。
- 单独计时 FTS5、读取/JSON 解码、内积；向量生成是本地替身，不能据此推断远程延迟。记录 seed 字节与检索/候选上限。
- 标准库精确 VP-tree 与同一 math.dist 内核的平扫比较：8/1024 维，独立单位向量及聚簇单位向量；归一化后欧氏距离与余弦排序一致。报告构建、查询 p50/p95、访问比例、与平扫 top-5 一致率。原型只作剪枝实验，不进入产品；不外推全部树/ANN 性能。
- 通过条件：作用域不泄漏、纠正/遗忘不复活、重复写入不膨胀、已有正文不重嵌入、每回合总注入不突破 4000 字节。性能报告如实记录，不事后指定通过阈值。

## 三配置任务对照

- 三配置：none（没有可用长期条目，但保留相同工具/提示）、facts（固定项目事实）、experience（同样事实 + 宿主认可的经验）。同一模型/工具/每任务 4 次模型与工具预算；各配置均新实例/独立数据库。
- 开发任务两类：CSV BOM 列提取与金额字符串转换；从各一个任务的真实工具观察与宿主结果学习经验，再在第二个独立开发任务中试用。只有宿主实际检查采用参数和产物通过，才认可候选。
- 固定未见回放六项：两份不同列名的 BOM CSV、两个不同金额输入、无 BOM 字节复制反例、整数原样返回反例。相同任务跨三配置配对；轮换配置顺序。经验不复制评测答案，只保留开发任务归纳；回放期间不继续学习。
- 固定事实：CSV 项目列名映射和金额目标单位。无记忆也可用同样的工具读取任务说明，不能人为移除其必要工具。
- 成功由精确产物与输入未变判定；实际采用需记录候选 ID + 相应方法参数。仅生成答案、召回条目或使用相同参数不算采用。
- 记录全部失败、工具错误、模型/工具次数、报告 tokens、端到端耗时。准备/提炼/试用成本另计；不使用模型裁判。
- 请求预算：最多 110 次聊天（含两类开发/提炼/试用与 18 个配对回放），单次最多 900 输出 tokens、45 秒、SDK retries=0；不做大规模远程 embedding。服务故障作为失败/未完成保留，不选择性补到全绿。
- 自动激活门槛：两类任务均出现可归因成功率提升，或在成功率不下降时两类均减少失败尝试，且反例没有新增错误；每条经验具备独立任务的验证来源。此小样本最多支持进一步试验，不宣称统计泛化。未达标则不开放自动激活，不修改样本或加反思循环补分。

## 有限语义质量检查

使用 BAAI/bge-m3，固定阈值 0.46（来自 R2.5 开发诊断，本轮不调阈值）。用新的中文事实、英语同义查询、词面相似但不相关问题和事实反转比较 FTS5/混合路径，最多 20 次 embedding 请求。记录漏检与误召回，不把持久化回归等同于模型准确率。

## 清理边界

删除确认无消费者的占位入口/重复失败召回；主运行路径解除对旧实现的偶然依赖。仍被公开 API 或冻结 benchmark 消费的模块明确保留并隔离，不为减少行数破坏现有入口。无新运行依赖，实际变更与未清理项记入状态文档。
