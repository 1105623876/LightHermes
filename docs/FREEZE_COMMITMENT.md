# A/B 冻结宣言

**日期**: 2026-08-15
**适用**: LightHermes v0.4.0 Active Memory 的 static / agentic A/B 与 holdout 评测
**状态**: 约束性。本文件在 A/B 开跑前生效，其修改需同步更新 ROADMAP，不得口头放水。

## 五条纪律

1. **锁死一切可变因素**：系统提示、停答点 trigger 规则、检索超参、随机种子、数据划分清单，在冻结时一次性写死。
2. **holdout 只跑一次**：成败都收。跑之前不接受“再验一眼”式预览。
3. **冻结后允许**：崩溃修复、trace 写坏修复、与策略无关的测试修复。
4. **冻结后禁止**：改 prompt、加关键词、调阈值、按开发集个例加规则。
5. **开发集只诊断**：不拿开发集“差 0.5pp 再拧一把”。

## 执行纪律

- 验证集连续看过 2 次仍未过线时，只许出诊断报告，不许第三轮拧参。
- 3.6 门槛是「Active Memory 默认开启」的发布闸，不是“代码能否合入”的闸。跑输就默认关闭发版并如实披露。
